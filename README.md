# Personal Minecraft Mod Browser

A private, unofficial integration for a local Modrinth App installation, intended to browse Minecraft content from Modrinth and CurseForge in one interface.

## Purpose

This project is for one person's use on one Windows computer. It is not operated or endorsed by Modrinth, CurseForge, or Overwolf.

The CurseForge integration is intended to provide:

- Mod search with Minecraft version and mod-loader filters.
- Installation of compatible files and required dependencies into local instances.
- Links and attribution to original CurseForge projects and authors.
- Downloads through API-provided URLs where authors permit third-party distribution.
- A manual download path through CurseForge when API downloads are unavailable.

## API access and current status

The local integration has been implemented, but live CurseForge search and installation have not yet been tested with an approved API key. API access is being requested for personal, low-volume use.

The user's API key remains on their computer and must not be published or included in this repository.

## Distribution

This repository contains the project description only. The modified application and its source code are private and are not distributed here. No mod files are hosted or redistributed by this repository.

There is no business model, advertising, subscription, donation program, or revenue associated with this personal integration.

## Author permissions

The integration is intended to respect each author's third-party distribution permissions and to avoid bypassing restricted downloads.

Minecraft content remains subject to its authors' licenses and the relevant platform terms.
